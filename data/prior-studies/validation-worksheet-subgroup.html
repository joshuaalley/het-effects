What counts

The question for every item is the same: does this file fit at least one model in which the effect of some variable is allowed to differ across units, subgroups, or contexts? Judge the code that runs, not comments.

Counts

  • y ~ x*z, x:z — product term in a formula
  • Stata c.x#c.z, i.x#i.z, x##z
  • gen xz = x*z then reg y xz x z — an interaction built by hand
  • The same model fit on two or more contrasting subsets to compare the effect: reg y x if female==1 and reg y x if female==0
  • Varying slope: (1 + x | group), (0 + x | group), Stata || g: x
  • Causal forest, bartc, bcf, meta-learners

Does not count

  • feols(y ~ x | country + year) — the pipe separates fixed effects; there is no interaction
  • areg, xtreg, i.country as controls
  • Varying intercept only: (1 | group), Stata || cntry: with nothing after the colon
  • One subset() or if defining the analysis sample, with no comparison across subsets
  • margins / slopes() on a model with no interaction
  • A variable whose name suggests a product but which is never actually constructed as one (e.g. gen foo_x_bar = .)
  • sum, ttest, merge, data cleaning
